📊 Retail Sales Performance Dashboard

Overview

This project analyzes retail sales data using Microsoft Excel. The dataset was cleaned with Power Query and analyzed using Pivot Tables and Pivot Charts to build an interactive dashboard.

Business Questions Answered

- Which product category generated the highest sales?
- Which category generated the highest profit?
- Which region performed best?
- Which customer segment generated the most revenue?
- How did sales change over time?
- Which shipping mode was used most frequently?

Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- GitHub


Key Insights

- Technology generated the highest sales.
- Technology also produced the highest profit.
- The West region recorded the strongest sales.
- Consumer customers contributed the largest share of sales.
- Standard Class was the most frequently used shipping mode.
- Sales increased overall between 2014 and 2017.
